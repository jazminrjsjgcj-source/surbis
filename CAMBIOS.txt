## 1. Los dos archivos de public/ se copian tal cual

    public/kiosk-sw.js
    public/kiosk.webmanifest

Y resources/js/lib/kioskWorker.ts.

## 2. Registrar el worker

En resources/js/app.tsx, al final del archivo:

    import { registerKioskWorker } from '@/lib/kioskWorker'

    // El quiosco necesita arrancar sin red tras un reinicio. El resto del
    // sistema no: sin conexion no hay nada que administrar.
    if (window.location.pathname.startsWith('/kiosk')) {
        registerKioskWorker()
    }

## 3. El manifiesto, SOLO en el quiosco

En resources/views/app.blade.php, dentro de <head>:

    {{--
        El manifiesto solo en el quiosco: es lo unico instalable. Ofrecer
        "instalar" en el panel daria un icono que abre una web que no
        funciona sin conexion.
    --}}
    @if (request()->is('kiosk*'))
        <link rel="manifest" href="/kiosk.webmanifest">
        <meta name="theme-color" content="#7a1f3d">
        <meta name="mobile-web-app-capable" content="yes">
    @endif

## 4. La cabecera que amplia el scope

Un service worker en /kiosk-sw.js solo puede controlar la raiz si el servidor
lo autoriza. En docker/nginx/default.conf, dentro del server:

    # El service worker del quiosco declara scope /kiosk aunque el archivo
    # este en la raiz. Sin esta cabecera el navegador lo rechaza.
    location = /kiosk-sw.js {
        add_header Service-Worker-Allowed "/kiosk";
        try_files $uri =404;
    }

Si tu nginx.conf esta en otra ruta, ajustala. Y despues:

    docker compose restart nginx
